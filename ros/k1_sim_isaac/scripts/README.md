# ros/k1_sim_isaac/scripts

Part of [k1-rl-isaac](https://github.com/thdhyan/k1-rl-isaac).

| File | What it does |
|---|---|
| `fleet_sim.py` | Isaac Sim multi-K1 fleet with namespaced ROS2 endpoints. |
| `isaac_fleet_vis.py` | Isaac Sim K1 fleet with visualization + OmniGraph ROS2 bridge + velocity policy. |
| `isaac_standalone.py` | Isaac Sim 6.0.1 standalone script for K1 simulation. |
| `k1_soccer_compose.py` | K1 Soccer — Multi-layered policy composition at runtime. |
| `k1_teleop_sim.py` | K1 VR-teleop sim (Isaac Lab, headless): K1 hanging in the air on a fixed base, ZED 2i stereo pair on ``Head_2``, chase camera, ROS 2 in/out. |
| `soccer_sim.py` | Isaac Sim soccer setup — Booster K1 + ball + goals + field, ROS-free. |
| `stereo_cam_test.py` | K1 stereo head capture — ZED 2i replica in Isaac Sim. |
